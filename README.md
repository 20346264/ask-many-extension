<h1 align="center">同问 AI · 多模型工作台</h1>

<p align="center">在一个页面中并排使用多个 AI，一次输入，同时提问。</p>

## 功能

- 在同一面板中并排打开 ChatGPT、DeepSeek、Claude 等模型
- 一次填写问题，并行填入并发送到已选择的模型
- 向 ChatGPT、DeepSeek、Claude、Gemini 同步发送图片或文件
- 等回答稳定后收集结果，生成结构化对比提示词
- 保存模型选择状态与窗口显示顺序，下次打开继续使用
- 支持自定义模型窗口排序：左侧栏拖拽排序或窗口顶栏 ◀ / ▶ 按钮微调，无刷新即时生效
- 直接使用浏览器中的网站登录状态，不需要 API Key

## 支持站点

| 站点 | 文字发送 | 图片/文件 |
|---|---:|---:|
| ChatGPT | 是 | 是 |
| DeepSeek | 是 | 是 |
| Claude | 是 | 是 |
| Gemini | 是 | 是 |
| 通义千问 | 是 | 暂不支持 |
| 腾讯元宝 | 是 | 暂不支持 |

站点页面更新后，输入框或发送按钮的选择器可能需要同步调整。

## 安装

1. 点击 GitHub 页面右上角的 **Code → Download ZIP**。
2. 解压 ZIP，并把目录放到长期保留的位置。
3. 在 Chrome 地址栏打开 **chrome://extensions/**。
4. 打开右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择包含 **manifest.json** 的目录。
7. 固定工具栏中的“同问 AI”图标，然后点击图标打开工作台。

更新代码后，在 **chrome://extensions/** 中点击扩展卡片上的“重新加载”，并重新打开工作台。

## 使用

1. 在左侧选择参与提问的模型，并在各模型页面完成登录。
2. 在底部输入问题；需要时添加图片或文件。
3. 按 **Enter** 或点击“发送”。
4. 等各模型回答完成后，点击“收集对比”。

**Ctrl+Enter** 和 **Shift+Enter** 用于换行。中文输入法选字时不会触发发送。

## 权限与安全

多数 AI 网站默认禁止被其他页面嵌入。为了实现单页并排显示，扩展会在工作台打开期间移除目标 iframe 响应中的 **X-Frame-Options** 和相关 CSP 响应头。

这条规则具有以下限制：

- 只在当前工作台标签页中生效
- 只作用于子框架请求
- 只覆盖 manifest.json 中声明的 AI 站点
- 工作台关闭或导航离开后自动撤销

扩展没有自己的远程服务器，不读取或保存 AI 网站的账号密码。登录状态仍由 Chrome 和各 AI 网站管理。

## 已知限制

- 首次使用需要分别登录各 AI 网站
- 人机验证、登录过期或站点新增 iframe 限制时，对应模型可能无法嵌入
- AI 网站更新页面结构后，自动填入、发送或收集可能暂时失效
- 当前通过开发者模式安装，尚未发布到 Chrome Web Store

## 目录

- **adapters.js**：站点选择器和 DOM 操作
- **background.js**：面板打开与 iframe 规则
- **content.js**：iframe 内消息处理
- **panel.html**：工作台界面
- **panel.js**：多模型编排
- **manifest.json**：Chrome 扩展清单
- **icons/**：多尺寸扩展图标
